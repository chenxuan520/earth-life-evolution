3. 段落间距是 y 间隙 2pt(同段) vs 9.2pt(跨段), 不是行高差;
4. 长标题/物种名折行需与书签标题归一化拼接匹配;
5. 全书总结是多版式混排: 50 物种表走 find_tables(), 其余小节按行型状态机分类;
6. [R16] 源文件自行碎片化, 人工校正, 脚本内有注释。
